Defectos comunes centralita ABS de la Mercedes SL R230 2001-2012

FALLO ABS/SBC Mercedes

Estos son algunos de los errores más comunes en el sistema de frenos ABS del modelo Mercedes SL R230 del año 2001-2012. Contacte con nosotros si no figura su error y consiga más información de nuestros servicios de reparación de ABS.

Las causas posibles son:

Error C2131 - Acumulador de presión defectuoso.

Error C223D - Fallo hidráulico: válvula de control de entrada delantera izquierda.

Error C22BD - Fallo hidráulico: válvula de control de entrada delantera derecha.

Error C233D - Fallo hidráulico: válvula de control de entrada trasera izquierda.

Error C235C - Comprobar componente A7/3 (Unidad hidráulica SBC).

Error C23BD - Fallo hidráulico: válvula de control de entrada trasera derecha.

Error C2498 - Tiempo de funcionamiento del componente A7/3 (módulo hidráulico SBC). Mantenimiento frenos sobrepasado límite de frenadas.

Error C249F - Tiempo de funcionamiento del componente A7/3 (módulo hidráulico SBC). Mantenimiento frenos sobrepasado límite de frenadas.

Error C25D4 - Fallo hidráulico: no hay presión o presión insuficiente.

Error C26F5 - Fallo interno unidad de control.

Error C26FB - No es posible aumentar la presión.

Rueda o ruedas bloqueadas.

Rueda o ruedas no frenan.
