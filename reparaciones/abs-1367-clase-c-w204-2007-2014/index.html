Defectos comunes centralita ABS de la Mercedes Clase C W204 2007-2014

10.0212-0200.4 - 10.0619-3590.1 - 10.0926-1596.3 - A 204 545 44 32

Estos son algunos de los errores más comunes en el sistema de frenos ABS del modelo Mercedes Clase C W204 del año 2007-2014. Contacte con nosotros si no figura su error y consiga más información de nuestros servicios de reparación de ABS.

Las causas posibles son:

Fallo control de motor de la bomba ABS.

Código de error 5001 o C1001 - Error de controlador ESP Interno (20481).

Código de error 5944 o C1944 - Error de controlador Interno (22852).

Código de error 5945 o C1945 - Error de controlador Interno (22853).

Código de error 7266 - Error comunicación CAN con control de distancia.

Error interno en el componente N30/4.

Error sensor de presión de frenos.

Rueda o ruedas bloqueadas.

Rueda o ruedas no frenan.
